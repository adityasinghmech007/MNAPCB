# STM32-Based Motor Control PCB

## 📌 Overview

This project is a custom-designed 2-layer motor control PCB developed for embedded motion control and automation applications. The board integrates an STM32 microcontroller, motor driver circuitry, INA226 current sensing, and onboard power management for efficient and reliable motor control.

The PCB was designed to support real-time motor actuation, current monitoring, and embedded control workflows for robotics and mechatronics systems.

---

## 🚀 Features

* STM32-based embedded control system
* Integrated motor driver interface for DC/Stepper motor control
* INA226 current and voltage monitoring
* Onboard DC power regulation circuitry
* Multi-voltage power distribution architecture
* 2-layer PCB optimized for compact routing and manufacturability
* Support for sensor interfacing and external peripherals
* Designed for rapid prototyping and embedded testing applications

---

## 🔧 Hardware Components

### Microcontroller

* STM32 MCU for real-time motor control and peripheral interfacing

### Current Sensing

* INA226 current/voltage monitoring IC
* I2C communication interface

### Motor Control

* Motor driver integration for controlling motors
* PWM and direction-based control signals

### Power Management

* DC-DC conversion stages for generating required operating voltages
* Power filtering and decoupling circuitry
* Separate logic and motor power domains
